# HS401 — Engineering Economics — PLAN

**Semester:** 4 · **Credits:** 2 · **Level:** Intermediate
**Theory:** 30 hrs · **Tutorial:** 15 hrs · **Tools:** Spreadsheet, Python (optional)

## Syllabus

### Unit 1 — Foundations (6 lectures)
1. What engineering economics is — decisions with money
2. Cost concepts — fixed, variable, marginal, opportunity
3. Cost estimation techniques
4. Break-even analysis
5. Sunk cost and relevant cost
6. Time value of money — the central idea

### Unit 2 — Interest and Equivalence (6 lectures)
1. Simple vs compound interest
2. Single-payment formulas — F/P and P/F
3. Uniform series — F/A and A/F
4. Gradient series
5. Nominal vs effective interest
6. Continuous compounding

### Unit 3 — Project Evaluation Methods (6 lectures)
1. Present worth analysis
2. Annual worth analysis
3. Future worth analysis
4. Rate of return — IRR and MARR
5. Benefit-cost ratio
6. Payback period — limitations

### Unit 4 — Depreciation and Taxes (6 lectures)
1. Depreciation — straight line
2. Declining balance and MACRS
3. Sum-of-years-digits
4. Salvage value and book value
5. Income tax basics for businesses
6. After-tax cash flow analysis

### Unit 5 — Risk and Decision Making (6 lectures)
1. Sensitivity analysis
2. Break-even and margin of safety under uncertainty
3. Expected value under risk
4. Decision trees
5. Replacement analysis
6. Inflation and its effect on analysis

## Practical Labs (15)

1. Cost estimation for a small software project
2. Break-even analysis on a spreadsheet
3. Compute present worth of a project
4. Annual worth comparison of two alternatives
5. IRR calculation on a real dataset
6. MARR and accept/reject decisions
7. Depreciation schedules in a spreadsheet
8. After-tax cash flow model
9. Sensitivity analysis — vary one input, plot impact
10. Scenario analysis — best/base/worst
11. Decision tree for a product launch
12. Replacement analysis — keep vs replace
13. Inflation-adjusted cash flow
14. Benefit-cost analysis of a public project
15. Full project evaluation report with recommendation

## Assignments

1. Cost and break-even problem set
2. Time value of money exercise
3. Project evaluation — three methods compared
4. Depreciation and tax analysis
5. Final project — a full engineering economic evaluation
